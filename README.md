# Align

Modular infrastructure for token projects on Solana

## Tech Stack

- **Next.js 14** - App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework
- **Material UI v5** - React component library
- **Solana** - Blockchain infrastructure
- **Supabase** - Backend, real-time database, authentication
- **Playwright** - E2E testing

## Features

### 🎯 Core Features
- **Project Dashboard** - Manage token projects and treasury
- **IP Verification** - Verify ownership of social accounts and brand
- **Team Transparency** - Show token holders who controls the token
- **Treasury Management** - Professional tools for buybacks and distributions

### 💬 Messaging System
- **Real-time DMs** - Direct messaging between token holders
- **Privacy Controls** - Granular settings for who can contact you
- **Block Users** - Prevent unwanted messages
- **Read Receipts** - Know when messages are read
- **Online Status** - See who's currently active
- **Message Search** - Find conversations quickly

- **Holder Verification** - Automatic token holder validation
- **Privacy Levels** - Public, Holders Only, or Private profiles
- **Block System** - Comprehensive user blocking

- **Karma System** - Track contributions and voting
- **Curation Voting** - Community-driven content moderation

## Getting Started

First, install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

```
/app          - Next.js 14 app router
/components   - React components
/lib          - Utilities and helpers
/public       - Static assets
/styles       - Global styles
/types        - TypeScript types
```
