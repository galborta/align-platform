## 🎯 Quick Start (5 Minutes)

### Step 1: Set Up Your Profile

**Why:** Your profile is required for messaging and helps others recognize you.

**How to:**
1. Click your wallet address in the top-right corner
2. Select **"Profile Settings"**
3. Click **"Edit Profile"**
4. Fill in:
   - **Display Name** (required for messaging)
   - **Bio** (optional)
   - **Avatar** (optional)
5. Click **"Save Changes"**

**Example:**
```
Display Name: CryptoBuilder
Bio: Building the future of DeFi on Solana
Avatar: [Upload your profile picture]
```

### Step 2: Configure Privacy Settings

**Why:** Control who can see your profile and send you messages.

**Privacy Level:**
- **Public** (Recommended) - Anyone can view your profile
- **Holders Only** - Only token holders in your projects
- **Private** - Profile hidden, messaging disabled

**Message Settings:**
- **Everyone** - Anyone can send messages
- **Holders Only** (Recommended) - Only mutual token holders
- **Nobody** - Disable all incoming messages

**Recommended for most users:**
```
Privacy Level: Public
Allow Messages From: Holders Only
```

This setting allows anyone to view your profile but only mutual token holders can message you.

### Step 3: Send Your First Message

**Method 1: From a User Profile**
1. Visit any project page
2. Click on a team member's profile
3. Click the **"Message"** button
4. Type your message and press **Enter**

**Method 2: From the Messages Sidebar**
1. Press `Cmd+M` (Mac) or `Ctrl+M` (Windows)
2. Click the **"+"** (New Message) button
3. Enter the wallet address
4. Click **"Start Conversation"**
5. Send your message!

## 🛡️ Privacy Settings Explained

### Privacy Levels

#### Public (Default)
```
Who can see your profile: Everyone
Who can message you: Based on "Allow Messages From" setting
Best for: Community engagement, project visibility
```

**Use when:**
- You're a project founder/team member
- You want to be discoverable
- You're comfortable with public profile

#### Holders Only
```
Who can see your profile: Token holders in your projects
Who can message you: Based on "Allow Messages From" setting
Best for: Semi-private accounts, selective visibility
```

**Use when:**
- You only want holders to find you
- You're managing sensitive projects
- You want limited discoverability

#### Private
```
Who can see your profile: Nobody
Who can message you: Nobody (messaging disabled)
Best for: Observers, privacy-focused users
```

**Use when:**
- You only want to browse projects
- You don't want any contact
- Maximum privacy is required

### Message Permissions

#### Everyone
- Anyone with your wallet address can message you
- No token holder verification required
- Most open option

#### Holders Only (Recommended)
- Must hold tokens in at least one common project
- Automatic verification
- Prevents spam from non-holders

#### Nobody
- All incoming messages blocked
- You can still send messages (if privacy allows)
- Complete message privacy

**Read Receipts:**
- ✓ (Single check) - Message sent

**Typing Indicators:**

**Search:**
- Click search icon in sidebar
- Type at least 3 characters

## 🚫 Blocking Users

### When to Block

Block users if they:
- Send spam or unwanted messages
- Harass or abuse
- Send scams or phishing attempts
- Violate community guidelines

### How to Block

**From a Conversation:**
1. Open the conversation
2. Click the **menu icon** (⋮) in the header
3. Select **"Block User"**
4. Choose a reason (optional):
   - Spam
   - Harassment
   - Inappropriate content
   - Scam
   - Other
5. Choose whether to delete message history
6. Click **"Block"**

**What Happens:**
- User can't send you new messages
- You can't send messages to them
- Existing conversation is hidden (if you chose to delete)
- They won't be notified

### Managing Blocked Users

**View Blocked List:**
1. Go to **Profile Settings**
2. Click **"Blocked Users"** tab
3. See all blocked users with reasons

**Unblock a User:**
1. Find user in blocked list
2. Click **"Unblock"**
3. Confirm action

**Note:** Unblocking doesn't restore deleted messages.

## ⚠️ Common Questions (FAQ)

### Can I message anyone?

**Answer:** It depends on their privacy settings.

- If they set **"Everyone"** - Yes, anyone can message them
- If they set **"Holders Only"** - Only if you hold common tokens
- If they set **"Nobody"** - No messaging allowed

**You'll see an error if you can't message someone.**

### Why can't I send messages?

**Possible reasons:**
1. You haven't set up your profile (display name required)
2. The user has messaging disabled
3. You don't meet their privacy requirements (not a holder)
4. You or they have blocked each other
5. You've hit the rate limit (10 messages/minute)

**Solution:** Check the error message for specific reason.

### What if someone is harassing me?

**Steps:**
1. **Block them immediately** (see "Blocking Users" section)
2. Choose to **delete message history** when blocking
3. **Report to team** via Discord/Twitter if serious
4. **Document evidence** (screenshot before blocking)

### Can I delete individual messages?

**Currently:** No, only entire conversations can be deleted.

**Workaround:** Block user and delete conversation history.

### Will blocked users know?

**No.** They won't receive a notification. Their messages will simply not be delivered.

### Can I export my messages?

**Currently:** No direct export feature.

**Future:** Message export feature is planned.

### How long are messages stored?

**Storage:** Messages are stored indefinitely unless:
- You delete the conversation
- You block the user and choose to delete history
- Your account is deleted

### What happens if I disconnect my wallet?

**Messages persist.** When you reconnect:
- All conversations remain
- Message history is intact
- You'll receive messages sent while offline

### Are messages encrypted?

**Storage:** Messages are securely stored in Supabase database.
**In Transit:** Encrypted via HTTPS/WSS.
**Note:** Messages are not end-to-end encrypted (team can access if needed).

### Can project admins see my messages?

**Privacy:**
- Project admins **cannot** see direct messages
- Only database admins can access (for moderation)
- Messages are not visible on blockchain

## 🔧 Troubleshooting

### Messages not appearing?

**Try:**
1. Refresh the page (`Cmd+R` or `Ctrl+R`)
2. Check your internet connection
3. Clear browser cache
4. Try a different browser

### Can't find a conversation?

**Check:**
1. **"All"** tab (not just "Unread")
2. Use the **search function**
3. User may have deleted their account
4. You may have deleted the conversation

### Typing indicator stuck?

**Usually:** Auto-resolves in 3 seconds.
**If stuck:** Refresh the page.

### Error: "Rate limit exceeded"

**Cause:** Sent too many messages too quickly.
**Limit:** 10 messages per minute.
**Wait:** 60 seconds, then try again.

### Profile picture not showing?

**Check:**
1. File size < 5MB
2. File format is JPG/PNG/WebP
3. Image is square (recommended)
4. Upload completed successfully

## 📊 Privacy & Data

### What Data is Stored?

**Profile:**
- Wallet address
- Display name, bio, avatar
- Privacy settings
- Last seen timestamp

**Messages:**
- Message content
- Timestamps (sent, read)
- Conversation participants
- Read/unread status

**Metadata:**
- Online status
- Blocked users list
- Typing indicators (temporary)

### Data Retention

**Messages:** Indefinite (unless deleted)
**Profiles:** While account exists
**Logs:** 90 days for security

### Data Deletion

**Delete Messages:**
1. Delete conversation (messages soft-deleted)
2. Block user with "delete history" option

**Delete Profile:**
1. Contact support
2. All messages will be removed
3. Conversations deleted
4. Action is irreversible
