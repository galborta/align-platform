═══════════════════════════════════════════════════════════════════════════════
🔄 AUTO-UPDATES
═══════════════════════════════════════════════════════════════════════════════

User earns karma in Project A:
─────────────────────────────────────────────────────────────────────────────
1. Entry created in wallet_karma (project_id = Project A)
2. Project A leaderboard updates instantly (shows user)
3. Homepage leaderboard updates instantly (aggregates all karma)

User earns more karma in Project B:
─────────────────────────────────────────────────────────────────────────────
1. New entry created in wallet_karma (project_id = Project B)
2. Project B leaderboard shows user
3. Homepage leaderboard shows: Project A karma + Project B karma

No manual sync needed - views aggregate on-the-fly! ⚡
