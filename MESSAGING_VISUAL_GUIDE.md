## 🔍 Finding Message Buttons

### On Any Page Header:
1. Connect your wallet
2. Look top right → Mail icon (📬)
3. Badge shows unread count
4. Click to open messages

### In Project Chat:
1. Go to any project page
2. Scroll to Holder Chat section
3. Hover over ANY user's message
4. See purple message icon appear
5. Click to start DM

### In Karma Leaderboard:
1. Go to any project page
2. Look at right sidebar
3. See "Top Contributors 🏆"
4. Each row has message icon (💬)
5. Click to message that user

### In User Profiles:
1. Click any user avatar/name
2. Profile modal opens
3. Large "Message" button visible
4. Click to start conversation

## 💡 Pro Tips

### Quick Actions
- **Cmd/Ctrl + M** anywhere to toggle messages
- **Click user in chat** to see message icon on hover
- **Badge shows count** so you know when new messages arrive
- **Green dot** means user is online now

### Smart Behavior
- Message buttons **hide for your own messages** (no self-messaging)
- Buttons **respect privacy settings** (may be disabled)
- **Real-time updates** across all buttons
- **Auto-open conversations** when clicking user-specific buttons

### Keyboard Navigation
- **Cmd/Ctrl + M**: Toggle sidebar
- **ESC**: Close sidebar or back to list
- **Enter**: Send message
- **Shift + Enter**: New line
