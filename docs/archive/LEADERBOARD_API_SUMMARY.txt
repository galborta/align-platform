1. GET /api/leaderboard
   → Fetch top karma earners
   → Query params: limit, period, projectId
   → Returns: Array of LeaderboardEntry
   → Cache: 60s fresh, 5min stale-while-revalidate

2. GET /api/leaderboard/user-rank
   → Get specific user's rank and stats
   → Query params: wallet (required), projectId
   → Returns: UserRankResponse with rank, karma, percentile
   → Cache: 30s fresh, 2min stale-while-revalidate
