♿ REDUCED MOTION (Accessibility)
═══════════════════════════════════════════════════════════════════════════════

When user enables "Reduce motion" in OS settings:

┌─ NORMAL (Animations Enabled) ──────────────────────────────────────────────┐
│  • ✅ Rows fade in sequentially                                            │
│  • ✅ Refresh button rotates 180° on hover                                 │
│  • ✅ Medal scales up 10% on hover                                         │
│  • ✅ Avatar lifts 2px on hover                                            │
│  • ✅ Spinner rotates continuously                                         │
└────────────────────────────────────────────────────────────────────────────┘

┌─ REDUCED MOTION (Animations Disabled) ─────────────────────────────────────┐
│  • ❌ Rows appear instantly (no fade-in)                                   │
│  • ❌ Refresh button no rotation (stays upright)                           │
│  • ❌ Medal stays same size on hover                                       │
│  • ❌ Avatar stays in place on hover                                       │
│  • ❌ Spinner static (no rotation)                                         │
│  • ✅ All content still visible and functional                             │
│  • ✅ Hover effects still show (background, color changes)                 │
└────────────────────────────────────────────────────────────────────────────┘

How to Enable:
├─ macOS:    System Preferences → Accessibility → Display → Reduce motion
├─ Windows:  Settings → Ease of Access → Display → Show animations
└─ Browser:  Respects OS setting automatically
