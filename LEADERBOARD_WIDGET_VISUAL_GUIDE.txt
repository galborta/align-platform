Real Avatar (if avatar_url exists):
┌────┐
│ 📷 │  40×40px image, rounded (999px radius)
└────┘  

Gradient Fallback (if no avatar_url):
┌────┐
│ 🎨 │  40×40px gradient circle with first letter
└────┘  

Gradient Colors (examples):
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│  A  │  B  │  C  │  D  │  E  │  F  │  G  │
│ 🔴  │ 🟡  │ 🟢  │ 🔵  │ 🟣  │ 🟠  │ 🟤  │
└─────┴─────┴─────┴─────┴─────┴─────┴─────┘

Algorithm:
1. Take first 8 chars of wallet address
2. Convert to base-36 integer
3. Modulo 360 for hue (0-359°)
4. Gradient: hsl(hue, 70%, 60%) → hsl(hue+60, 70%, 50%)

Result: 360 unique color combinations
