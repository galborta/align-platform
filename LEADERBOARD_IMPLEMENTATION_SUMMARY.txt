📡 API ENDPOINTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GET /api/leaderboard
─────────────────────────────────────────────────────────────────────────────
Fetch top karma earners

Query Parameters:
• limit:     1-100 (default: 10)
• period:    day|week|month|all (default: all)
• projectId: UUID or null (default: null = global)

Response: Array of LeaderboardEntry
Cache:    60s fresh, 5m stale-while-revalidate


GET /api/leaderboard/user-rank
─────────────────────────────────────────────────────────────────────────────
Get specific user's rank and stats

Query Parameters:
• wallet:    Solana wallet address (required)
• projectId: UUID or null (optional)

Response: UserRankResponse with rank, karma, percentile
Cache:    30s fresh, 2m stale-while-revalidate
